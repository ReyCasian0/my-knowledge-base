Import text documents

Select TXT, Markdown, CSV, JSON, PDF, or Word (.docx) files. Their text will be saved in your local library and included in backups. Use Original file on the saved record to keep the file and its formatting separately.

For this first version, each file must be under 2 MB.

PDFs need selectable text. Word import reads the main document text, including tables. Scans and pictures need text recognition first. If a selected file fails, the whole selection is skipped.

Backup and restore

Export a separate JSON backup before making major changes. Keep it in Files, preferably in more than one safe location. Backups include records and extracted text. Download attached originals separately.

Restoring replaces the current catalog. Export your current catalog first.
